# رياضيات السادس العلمي

شرح مصوّر وتفاعلي لفصول كتاب الرياضيات للصف السادس العلمي الستة، مع تحدّي الفرق والمختبر التفاعلي، بنفس تصميم كتابي الكيمياء والفيزياء.

- **الموقع:** https://zraij.github.io/Mathmatics/ (يحتاج تسجيل دخول)
- **إدارة الحسابات:** https://zraij.github.io/Mathmatics/admin.html (لصاحب الموقع فقط)

محتوى الصفحة مشفّر، ولا يُفتح إلا بحساب صحيح. الحسابات محفوظة في `users.json` بشكل مشفّر، وتُدار من صفحة الإدارة.
